## 运行

开发分支的交互音效复用上游管理器与音频，区分 BGM、界面音效、战斗音效和干员语音。覆盖范围与待验项目见 [复用及验收报告](docs/AUDIO-MAPS-REVIEW.md)；不表示生产站点已更新。

自托管房间现通过上游原有大厅/房间版本选择器开放四个官方版本预览，并复用隔离的对局进程；同时最多启动一个非默认版本进程。静态站点/浏览器本地引擎仍使用默认第二期下半。**非默认版本房间尚无增强版检查点持久化**。各版本的地图池、模式限制与上游预览提示保留不变，详见 [地图支持矩阵与素材限制](docs/AUDIO-MAPS-REVIEW.md#map-support)。

使用本轮 SQLite 恢复后端及 RC 检查采用的 **Node.js 26.7.0**。剩余三项串行测试失败已修复，但尚未在修复提交上重跑完整上游测试，详见 [RC 复验报告](docs/RELEASE-CANDIDATE-2026-10-31.zh-CN.md)。当前构建无需提前批量下载美术资源。

## 增强版开发预览

游戏内点击 **「战术终端」**：

- **事务保险库 v3**：IndexedDB 原子提交，保留旧版原文与校验副本，支持迁移目录回退/撤销和旧标签页冲突归档。导入仅加入候选，须引擎确认后才激活；完成对局后保留备份。
- **复盘 v2**：稳定事件引用、位置/生命采样、事件分页，明确显示缺失、截断与记录中断。相同种子重试独立记录，继续兼容 v1；跨记录比较不推断因果。
- **战术教练 2.0**：本地规则将观察、假设和调整建议分开，每条附事实或事件引用，点击即可核查。可选模型卡片必须引用本场证据；提供商密钥留在后端。
- **自定义挑战**：固定种子、部署上限、禁用干员、禁止刷新/装备，支持 JSON 导入导出；挑战结算与标准成就隔离。
- **多人架构**：自托管后端恢复上游房间协议、共享对局、同盟模拟与身份重连；附带纯数据 Mod 示例，添加实验干员与首回合训练资金。
- **外部素材**：角色、Spine 模型、立绘、音乐、音效和语音地址按需外部加载，提供 atlas 适配及可用镜像回退。构建包含 17,098 条资源映射与 710 组 atlas 元数据；映射完整不代表已逐条验证网络可用性。

**这不是任意时刻存档。** 战斗中退出仍恢复至最近一次休整。引擎或规则指纹不兼容时保留原档供导出，阻止直接恢复；不能保证所有未来版本都能继续所有旧局。重要进度应在更新或清理浏览器前导出。

**线上默认仍是本地单人。** 联机必须另外运行自托管后端，默认房间仍只保存在内存。使用 `--state-dir .personal-state` 可为受支持的默认同盟房间启用“最近已提交休整检查点”恢复：验证原重连凭据、全员确认后继续，检查点之后的操作、战斗和未提交结算会回退。原站账号同步和远程 AI 队友尚未接入。可选大模型教练负责分析结果，不代替队友操作；本地休整存档不保存联机房间。

复盘最多保留 30 条，每场最多 600 个采样画面与 2,500 个事件；它是示意回放，不是完整录像或可恢复战斗。旧战绩只能导入汇总，不能补出过去未记录的时间轴。外部素材需要网络，来源变化可能造成缺图或无声。
