## 运行

需要 **Node.js 22.9+**。当前构建无需提前批量下载美术资源。

```sh
npm ci
npm --prefix upstream ci --omit=dev
npm run build
npm run server
```

- [http://127.0.0.1:4174/](http://127.0.0.1:4174/)：浏览器内单人引擎。
- [http://127.0.0.1:4174/?server=local](http://127.0.0.1:4174/?server=local)：连接正在运行的房间服务器。
- 局域网：使用 `npm run server -- --host 0.0.0.0`，各设备访问 `http://本机局域网IP:4174/?server=local`，通过房间码加入。

静态托管发布 `dist/` 即可。现有线上站点保留私人访问权限，公开源码不改变站点权限。静态站点本身不运行联机房间服务器。

## 1.1 版：个人战术实验室

游戏内点击 **「战术终端」**：

- **存档保险库**：双副本校验、迁移旧版休整存档、损坏回退、手动保留、导入导出与兼容检查；完成对局后保留备份。
- **战斗复盘**：逐秒位置与生命示意、拖动时间轴、播放倍速、死亡/漏敌/技能事件、干员输出与治疗排名、承伤统计和跨记录比较。
- **战术教练**：无需密钥的本地规则建议；可选自托管大模型接口，仅在主动点击分析时发送战斗摘要。模型提供商密钥留在后端。
- **自定义挑战**：固定种子、部署上限、禁用干员、禁止刷新/装备，支持 JSON 导入导出；挑战结算与标准成就隔离。
- **多人架构**：自托管后端恢复上游房间协议、共享对局、同盟模拟与身份重连；附带纯数据 Mod 示例，添加实验干员与首回合训练资金。
- **外部素材**：角色、Spine 模型、立绘、音乐、音效和语音地址按需外部加载，提供 atlas 适配及可用镜像回退。构建包含 17,098 条资源映射与 710 组 atlas 元数据；映射完整不代表已逐条验证网络可用性。

**这不是任意时刻存档。** 战斗中退出仍恢复至最近一次休整。引擎或规则指纹不兼容时保留原档供导出，阻止直接恢复；不能保证所有未来版本都能继续所有旧局。重要进度应在更新或清理浏览器前导出。

**线上默认仍是本地单人。** 联机必须另外运行自托管后端，房间只保存在服务器进程内，重启会丢失当前房间。原站账号同步和远程 AI 队友尚未接入。可选大模型教练负责分析结果，不代替队友操作；本地休整存档不保存联机房间。

复盘最多保留 30 条，每场最多 600 个采样画面与 2,500 个事件；它是示意回放，不是完整录像或可恢复战斗。旧战绩只能导入汇总，不能补出过去未记录的时间轴。外部素材需要网络，来源变化可能造成缺图或无声。

## 指南与开发入口

**[存档、联机、教练、挑战及 Mod 配置指南](docs/PERSONAL.zh-CN.md)**（[English](docs/PERSONAL.md)）。

- `personal/`：本地引擎适配、存档、战术终端、素材适配、自托管后端和测试。
- `upstream/`：上游实现、数据及原文档；修改规则请遵循其数据生成与插件流程。
- `personal/examples/`：可导入的挑战配置与纯数据 Mod 示例。
- `dist/`：生成结果，不提交 Git；旧素材缓存脚本仅作为可选维护工具保留，构建不再要求执行。
