## 必须在实现前锁定的决策

以下为提案默认值，不是暂停文档工作的理由；进入对应任务时用可运行 PoC 和测试结果决定是否调整。

| 决策 | 建议默认 | 不能未经评审扩大的范围 |
| --- | --- | --- |
| 多人首次持久化 | 单机、默认版本、无玩法插件、多人 PREP 检查点 | 不宣称全阶段零丢失，不直接放开任意插件或四版本 |
| 停服时间 | 恢复检查点剩余计时，停服期间不推进游戏 | 不自动补算离线收益或让旧结果继续影响恢复后的局 |
| 数据库 / Node 版本 | SQLite 事务 + WAL，PoC 锁定驱动及运行版本 | 不在验证前提高最低版本或假定现有 Node 就满足要求 |
| 旧存档未知兼容组合 | 保留、只读、可导出 | 不强改版本指纹或丢弃未知干员/装备 |
| 旧回放缺失资料 | 继续显示已有采样/汇总，明确缺失 | 不生成不存在的时间点、事件或技能推理 |
| 模型不可用 / 引用无效 | 本地规则降级 | 不把模型服务当游戏/存档关键依赖 |
| 生产上线 | 完整预览验收后单独批准 | 本轮文档、后续代码提交均不自动等于生产部署授权 |

## 持续风险管理

每个任务的提交说明列出关联风险 ID、对应测试及仍不覆盖的分支。数据丢失、结算重复、原版规则变化列为阻断发布问题；UI 改善不得掩盖这些失败。新发现的未知规则先标为未知并引用原数据/实现，不能为赶功能补写猜测。
