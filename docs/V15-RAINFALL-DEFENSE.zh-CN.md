# 雨夜防线 — v15 原创关卡原型

[English](V15-RAINFALL-DEFENSE.md)

这是《卫戍协议：盟约》中的**非官方原创关卡**。标准模式与八张原版地图池不变；Public v14 站点不更新。本分支仅用于审查，没有自动部署工作流。

## 如何试玩

执行 `npm run build`，再运行 `node personal/custom-stage-preview.mjs`，打开 `http://127.0.0.1:4185/`。本地验收页默认静音并阻止外部资源，用于验证无需额外素材的回退表现；不会注入阵容、存档或胜利结果。正常构建继续使用现有外部素材及音效适配器。

从「战术终端 → 自定义挑战 → 雨夜防线」进入，开始模拟、确认简报、选择策略干员，再招募和部署。使用盟约版本的单人模拟经济、干员、技能、装备与盟约机制。固定种子为 `20261102`；复现结果还需要相同的策略干员、购买顺序、部署位置、朝向和操作。

上下两个入口汇流至同一条防线，可集中防守交汇处或分守两路。三轮敌人依次为 8 个史莱姆、8 个史莱姆加 4 只猎狗、8 只猎狗加 5 个史莱姆及 1 名重装防御者，全部复用上游敌人定义。每轮 65 秒真实时间，对应 130 秒模拟时间。

**通关：完成三轮，仍有生命且累计有效漏敌不超过 4。失败：漏敌超过 4，或生命耗尽。** 没有 Boss 回合，也不发放原版奖励。结算归入上游 Mod 战绩分类，复盘标记原创关卡、内容版本、校验指纹和独立 runId。

**本关不支持存档恢复。刷新、离开即结束本次挑战。** 原创关卡不会写入、覆盖或清除标准休整检查点；返回大厅后仍可继续原版存档。它不是任意时刻存档。

## 实现边界

复用上游 manifest v2 纯数据插件、地图 Schema、部署格派生、Grid 寻路、波次、Match/Battle、浏览器战斗 Worker、Pixi/Three 渲染器及已有动态反馈。没有第二套引擎、寻路、地图渲染器或编辑器，没有修改 upstream 文件。

纯数据插件能增加地图、波次和模式，但不能提供当前静态浏览器宿主的「三轮结束/累计漏敌上限」生命周期。因此 personal 层仅在真实结算之后增加本实例的终局判定。单独将 JSON 插件安装到未适配的上游服务器，不视为受支持的完整玩法。上游 Studio 的服务端编辑能力也没有重新移植。

关卡配置位于 `personal/stages/rainfall-defense/`。`content.json` 同时包含地图、波次、模式及 `options.originalStage` 元数据，后者与内容一同校验，避免描述和实际规则脱节。构建复用上游校验器并验证每一段路径可达；加载验证内容哈希和文件长度，拒绝脚本与越界路径。发布房间状态时一次性携带正确的内容配置，失败不会静默替换成原版地图。

环境使用原创程序化雨滴、薄雾、水纹与设备灯，不要求导入 3D 素材。配置支持 rain/none、雨滴颜色及最多 24 个可选图元，仍受现有低/中/高画质和静态/减少动态效果限制。装饰不参与碰撞、寻路、伤害或输入处理。

当前仅支持本地单人、盟约版本和默认程序化地图；不支持此关卡的多人、其他官方版本或导入原版 3D 场景。继承模式的第 4–9 回合及 Boss 权重属于不可到达的配置，宿主在第三轮结算后结束，并移除本关无用 Boss 简报。

完整布局、路线、复用审计与扩展方式见英文文档；实际测试与未验证项目见[验收记录](V15-ACCEPTANCE.md)。有限的固定种子验证不等于所有阵容的平衡保证。保留 GPL、原作者署名及第三方权利说明，不新增游戏美术再分发。
