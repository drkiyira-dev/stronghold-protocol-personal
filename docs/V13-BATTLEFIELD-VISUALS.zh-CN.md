# v13 第一阶段：战场环境动态预览

[English](V13-BATTLEFIELD-VISUALS.md)

基于 main `8d4207ef42ab37ec1d3cff36db9b6c107ed0e3d5`，为《卫戍协议：盟约》Enhanced Edition 的两张现有地图加入环境细节。生产 Sites v12 继续保持 Public，未更新；本分支须经审查和单独部署批准。

## 本阶段实际功能

| 原版地图 | 环境表现 | 复用方式 |
| --- | --- | --- |
| `act2autochess_m03`，战场 #07「排气格栅」 | 排气格的柔和光泽、更缓慢轻柔的定向蒸汽 | 复用上游 `TileField` 烟雾和 `fxAtlas`，不增加第二套发射器；预算仅用于当前视野的有效排气格。 |
| `act2autochess_m04`，战场 #08「涨潮控制」 | 在原有水面光泽上增加小幅扩散波纹 | 使用既有摄像机投影与 Pixi 图层，波纹限制在真实深水格内。 |

地图池、坐标、路线、部署合法性、地形效果和战斗计算均未修改。测试通过现有挑战功能使用 HARD（界面显示「绝境模拟」）种子 5、3，仍由原地图池选择战场，不强制解锁地图。第二阶段战斗操作反馈和第三阶段其他地图扩展等待本阶段审查。

代码位于 `personal/battlefield-*.mjs`。构建适配器只连接既有渲染循环、地形动画和 Three 材质时钟；上游接口变动时构建会失败。未修改受版本控制的 upstream 源码，未替换渲染器、Spine 或技能特效，未引入新框架或素材包。效果位于干员、阴影和部署提示下方，不能接收输入，也不发送模拟事件。

## 设置、预算与释放

在 **设置 → 动态环境效果** 中切换动态或静态，沿用 v12 的设置键和原有画面质量。首页、大厅布局不变，没有第二套画质或存档迁移机制。

| 条件 | 新增投影面片 | 复用蒸汽 |
| --- | --- | --- |
| 低画质、静态、系统减少动态、隐藏页面、战斗结束 | 0 | 隐藏 |
| 中画质 | 最多 8 个 | 当前有效排气格最多 8 个原有精灵 |
| 高画质 | 最多 24 个 | 当前有效排气格最多 16 个原有精灵 |
| 已加载原版 3D 场景 | 不叠加新增面片 | 由原版场景负责环境表现 |

选定的单人休整视野实际使用 2 个排气格面片或 6 个水面面片；较大的上限供原有联合战场视野使用。静态模式只暂停非必要环境时钟，不冻结技能、伤害、漏怪提示、摄像机或战斗逻辑。战术气流方向提示保留上游行为。

没有新增 RAF 循环、定时器、纹理、渲染目标、滤镜或 WebGL 上下文。切换地图、隐藏页面、关闭动态效果、上下文丢失、结算及离开战场时释放所拥有的面片；销毁时解除设置订阅和画布事件。Pixi 仍负责恢复 WebGL。新增效果出错不会跳过引擎逻辑；无 WebGL 时仍使用上游 DOM 简化战场并可完成对局。

可选原版 3D 场景复用既有材质和水面时钟，避免重复叠加。素材导入、缓存与恢复机制沿用既有实现。本阶段用合成数据检查时钟及叠加抑制契约，**不宣称重新完成完整原版 3D 素材实测**；新增功能不要求导入素材。

## 本机复现与测试

依次执行 `npm ci`、`npm --prefix upstream ci --omit=dev --ignore-scripts`、`npm run build`、`node personal/battlefield-preview.mjs`。

打开 `http://127.0.0.1:4183/?seed=5` 或 `?seed=3`。建议用独立测试浏览器环境：此本机 QA 页面会在该 origin 的存储中选择固定种子挑战。输入代号并开始，再点击 **LOCAL V13 QA → 准备真实对局**。购买、部署和战斗均走真实 worker 消息；画质按钮使用现有共享设置。“战斗至 R2”运行实际战斗及结算；测量按钮采集静态、动态、再次静态三组数据。

预览只有静态文件服务和限量报告接收接口，没有房间后端或素材代理。QA 页面、初始化脚本和报告接口均不进入发布包。串行运行 `npm test`、`npm run check:dist`、`npm run test:browser`。新测试覆盖可见动画、画质、静态、减少动态、隐藏页面、真实 WebGL 丢失恢复、反复开关、拾取与部署、R1 至 R2、离场释放及无 WebGL 对局。已有测试继续覆盖存档、复盘、教练、音效、素材导入和地图。

实测环境、性能数值及限制见 [验收报告](V13-ACCEPTANCE.md)。英文说明中包含开关对比图；公开截图阻断了第三方素材，只显示 GPL 程序化场景。静态图片不能独自证明动画，另有跨帧数值检查与原生浏览器观察。此次不是完整九回合、多人/Boss、手机实机或长期温度压力验收。

预览在客户端初始化前同步静音，第一次点击开始也不会出声；之后可在设置中手动解除，准备对局会保留这一选择。只影响专用本地测试地址，保留其他音量偏好，不修改生产音频默认值。原生浏览器测量时必须保持窗口可见，隐藏窗口的性能数据无效。
